## What this is

Just a place to dump notes and code while I learn the ML library stack, starting with numpy and pandas. Every topic gets its own folder with a `.py` file for practice code and a `README.md` for notes, so it doubles as quick reference later instead of me rewatching hour long videos for one line of syntax.

Structure isn't locked in from day one, folders get added as I actually get to each topic.
